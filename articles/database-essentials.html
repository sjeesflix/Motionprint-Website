Database Essentials: Save, Organize, and Reopen Your Analysis Projects

5 min read
New in v1.0.1

The Database is your project library — a permanent collection of every analysis you save in Motionprint Ergo. Instead of re-running the same assessment from scratch, you can reopen any saved project, modify it, or export it again with updated settings. This guide covers how to save projects, browse your library, filter by methodology or status, and understand the difference between archiving and deleting a project.

1 What is the Database?

Before v1.0.1, every analysis in Motionprint Ergo was a one-time workflow: you ran a report, exported it, and moved on. The Database changes that. It stores every project you choose to save — including the full calculation data, custom moments, settings, and metadata — so you can return to any assessment at any point.

This is especially valuable for teams running repeated assessments at the same workstations, for compliance workflows that require an audit trail, and for any situation where you need to compare results across time or methodology versions.

2 Saving a project

Where to save

After generating results for a NIOSH or KIM-LHC assessment, you'll find a Save Project button on the results page, next to the Edit and Export buttons. One click stores the project in the database — no manual naming or file management required. Motionprint Ergo captures all relevant metadata automatically at the moment you save.

What gets saved

A saved project is a complete snapshot of your analysis. This includes:

  • Analysis methodology (NIOSH or KIM-LHC)
  • Complete calculation data and findings
  • Custom critical moments, if you created any
  • Evaluator and operator names, if privacy settings allow
  • Project metadata: dates, workstation name, and subject information
  • The exact analysis settings used — preserved for later comparison
No manual management needed

The app handles all database storage for you. There are no files to name, no folders to organize. Just click Save Project and the database does the rest.

3 Browsing and filtering your projects

Accessing the Database

Click Database in the main navigation to open your project library. You'll see all saved projects in a list view showing the project title, methodology, creation date, and current status. From here, you can open any project directly or use filters to narrow down what's displayed.

Using filters to find projects

As your library grows, filters help you get to the right project quickly. You can filter by:

  • Methodology — show only NIOSH assessments, only KIM-LHC, or both
  • Status — draft, final, or archived projects
  • Risk level — filter by low, medium, or high risk based on calculated results
  • Multiple values — combine filters, for example "KIM-LHC AND High-Risk"

Use filters to quickly find all KIM-LHC assessments completed last month, or all high-risk projects awaiting management review — without scrolling through your entire library.

4 Archive vs. delete

The database gives you two ways to remove a project from your active list: archiving and deleting. They are not the same thing, and choosing the wrong one can have consequences.

When to archive

Archiving hides a project from your main library view without removing it from the database. Archived projects remain fully recoverable — you can reopen them at any time by filtering for archived status. Use archiving for completed seasonal projects, older methodology versions you no longer need day-to-day, or any project you want out of your active list but may need to reference later.

When to delete

Deleting permanently removes a project from the database. This action cannot be undone. Before deleting, ask yourself whether the project could be needed for an audit, compliance check, or future comparison. Delete only for test runs, accidental saves, or clear duplicates.

Deletion is permanent

If you're unsure whether you'll need a project again, archive it instead of deleting it. Archiving is always reversible; deletion is not.

5 Understanding project status

Each project in the database carries a status that reflects where it is in your workflow. You can update the status when reopening a project or through the project settings.

  • Draft — saved but not finalized; findings may still be modified
  • Final — marked as complete and ready for reporting or export
  • Archived — moved out of the active list; recoverable at any time

Status is also one of the available filters in the database view, making it straightforward to separate ongoing work from completed assessments.

6 Settings and reopened projects

This section is important if you ever change your analysis preferences between saving and reopening a project.

When a settings dialog appears

When you open a saved project, Motionprint Ergo checks whether your current analysis settings match the settings used when the project was originally created. If they differ — for example, you've changed a reference mass, NIOSH equation variant, or filtering threshold — the app will ask which settings to use before displaying the results.

Why this matters

Analysis settings directly affect calculations and risk classifications. A small change in reference mass or asymmetry thresholds can shift a result from medium to high risk. The settings dialog ensures you're always in control of which methodology your findings reflect.

  • Choose Use Current Settings to recalculate findings with your latest preferences — useful when you want to apply updated company standards or verify previous results with new methodology.
  • Choose Use Saved Settings to preserve the original analysis exactly — useful when maintaining historical accuracy, comparing against previously reported data, or verifying for compliance.
Example

You originally ran a NIOSH assessment using a 25 kg reference mass. You later changed your default to 23 kg. When reopening the project, you'll be asked which mass to use — preserving the original methodology or applying the new standard.

When in doubt, document your choice in the project's Notes field so team members can understand why findings may differ between exports of the same project.

The database keeps a complete history of your assessments — save your next analysis and explore the filters to get a feel for it. When you're ready to revisit a stored project, see How to Reopen a Saved Project and Continue Your Analysis for the full step-by-step workflow.
