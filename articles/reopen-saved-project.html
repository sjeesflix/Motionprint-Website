How to Reopen a Saved Project and Continue Your Analysis

Saved projects give you the ability to revisit any previous analysis in Motionprint Ergo. Whether you need to edit findings, apply new settings, or export with updated company methodology, reopening a project takes just a few clicks. This guide walks you through the entire workflow — from finding your project in the database to making changes and exporting refreshed results. You'll need a project already saved in the database; if you haven't saved one yet, see Database Essentials first.

1 Locate your project in the Database

Click Database in the main navigation to open your project library. You'll see a list of all saved projects with their title, methodology, creation date, and status displayed at a glance.

If your library has grown, use the filters to narrow the view. You can filter by methodology (NIOSH or KIM-LHC), status (draft, final, or archived), or risk level. Combine multiple filters to zero in quickly — for example, "KIM-LHC AND Final" shows only completed KIM-LHC assessments.

Tip

Use the risk level filter if you're looking for a specific subset — for instance, all high-risk projects from a particular workstation batch.

2 Open the project

Click any project in the list to open it. Motionprint Ergo retrieves all saved data and takes you directly to the results page, with findings, custom moments, and metadata restored exactly as they were when you last saved.

Opening a project does not modify it. You can review the results, close the view, and the original project remains unchanged in the database. Changes are only written back when you explicitly click Save Project.

3 The settings dialog

This is the most important step to understand. If you've changed any analysis settings since the project was originally created — reference mass, equation variant, risk thresholds, or similar — a dialog will appear before the results load, asking which settings to use.

Use Current Settings

This option applies your latest analysis preferences and recalculates the assessment using the new methodology. Findings may change as a result. Choose this when you want to:

  • Apply updated company standards to an existing assessment
  • Test how different parameters affect a risk classification
  • Compare old data against a new methodology

Use Saved Settings

This option preserves the exact settings from when the project was originally created — the findings stay as they were originally calculated. Choose this when you want to:

  • Maintain consistency with previously reported or exported findings
  • Verify results for compliance or an audit trail
  • Keep the original methodology intact while only editing notes or metadata
When in doubt

If you're unsure which to pick, choose Use Saved Settings. This preserves the original analysis and avoids unintended recalculation. You can always reopen the project again later with current settings if needed.

Pro tip

Want to compare both versions? Open the project twice — once with saved settings, once with current settings — and export the results separately. Each export captures the date and settings applied, so you can reference both versions clearly.

4 View and edit your findings

Once the project is open, you're back on the results page with full access to everything that was saved.

What you can do

  • Review all findings and critical moments as originally saved
  • Click Edit to modify analysis notes, add new findings, or adjust risk rankings
  • Add, hide, or review critical moments in the timeline
  • Update project metadata: title, tags, notes, and workstation name

Saving your changes

Click Save Project to write your changes back to the database. All edits are permanent once saved. If you want to discard changes instead, click Back or close the results view — the original project remains untouched.

Document your settings choice

If you're working in a team, add a note in the Notes field explaining which settings were used and why. This helps teammates understand why findings may differ between different exports of the same project.

5 Re-export with updated results

Once you've reviewed or edited the project, you can export the results as PDF or Excel using the Export button in the tab bar — exactly as you would from a fresh analysis. The export uses the current display: either the saved settings or the recalculated results, depending on your choice in Step 3.

Exported files include both the original project date and the export date, so your records clearly show when the assessment was conducted and when the file was generated. See Exporting Reports (PDF & Excel) for full details on export formats and filename templates.

6 Real-world scenarios

Scenario 1 — Maintaining a historical record

Your team used a 25 kg reference mass throughout Q1 2026. In June, company policy changes to 23 kg. You reopen a Q1 project to produce a compliance report and choose Use Saved Settings. The export reflects the original 25 kg methodology — an accurate record of the assessment as it was conducted at the time.

Scenario 2 — Applying updated standards

You want to re-analyze older data under the new 23 kg standard to see how the risk classification changes. You reopen the same Q1 project and choose Use Current Settings. The findings recalculate with 23 kg — and you can export a second file labelled clearly as "re-analyzed under updated methodology."

Scenario 3 — Editing notes without recalculating

You need to add a corrected workstation name and a supervisor's review note to a final report. You reopen the project, choose Use Saved Settings, update the metadata fields, and save. The findings are unchanged; only the project notes are updated.

7 Troubleshooting

A project won't open
Check the status column in the database — archived projects are hidden from the default view. Switch the status filter to "Archived" and check whether the project appears there. If it doesn't appear at all, it may have been deleted.
Findings changed after reopening
You likely selected Use Current Settings at the dialog. Reopen the project again and choose Use Saved Settings to restore the original findings.
I can't remember which settings I used originally
Choose Use Saved Settings — this restores the project to its exact original state, regardless of what your current defaults are. Check the project's Notes field for any documentation left by you or a team member.
The settings dialog didn't appear
If your current analysis settings exactly match the settings saved with the project, no dialog is needed — the app opens the project directly without prompting. This is normal behavior.

Reopening projects is one of the most powerful ways to get value from the database — it turns every assessment into a living record you can return to, refine, and re-export. Next, learn how to run a new NIOSH assessment or configure your export settings for consistent report formatting.
